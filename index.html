FAQ

Something else? Ask in the Discord.

Is Omnity really free?

Yes. Every script here is free, with no key system and no ad links in the way.

Which executors work?

Any executor that supports loadstring and HTTP requests. If yours cannot run it, the loader says so in a notification instead of failing silently.

Can I get banned?

Any script carries some risk. Play on an alt account if you care about your main, and avoid blatant use in front of other players.

The menu did not open. What now?

Check that you ran the right script for the game you are in. The loader shows a notification explaining any problem. Still stuck? Ask in the Discord with a screenshot.

Can you add my game?

Request it in the Discord. The most requested games get built next.
